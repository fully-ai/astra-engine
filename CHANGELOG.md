# Changelog

## v0.1.0-alpha.1 (2026-11-18)
- Initial Alpha release: C++20 core math, RFC-8259 JSON, sparse ECS + scene serialization + keyframe animation, binary glTF 2.0 / `.glb` & `.wav` asset pipeline, OpenGL 3.3 Core PBR + directional shadow renderer, AABB/sphere physics + raycast, AstraScript VM with hot reload, SDL2 visual 3D editor, build packager CLI, and playable 3D sample game (`astra-sample`).
